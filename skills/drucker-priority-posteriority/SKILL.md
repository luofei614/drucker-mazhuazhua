# 优先/延迟必须成对（含四勇气法则与聚焦三律）

## R — 原文 (Reading)

> 那些"做这么多事"，而且是这么多难事的人，"秘诀"就在于每次只做一件事。
>
> ……有效管理者在时间方面总会留出一点余地。
>
> — 德鲁克，第5章 要事优先

> 优先任务与延迟任务的区别在于：优先任务是你真正想做的那件事，
> 延迟任务则是看起来紧急、值得做、却会让你偏离真正想做的事的"分心之事"。
>
> — 德鲁克，跋《有效管理者必须定下大量的延迟任务》

## I — 方法论骨架 (Interpretation)

常识只有"优先级"没有"延迟级"，德鲁克说二者必须**成对**，且**延迟级才是真难点**。
理由：列出优先清单相对容易（所有人都喜欢列 to-do），
但明确说出"本季度不做"需要勇气（因为延后实际上就是放弃）——
正因如此人们害怕，于是"两头下注"，每个都做一点，结果一事无成。

排序的方法不是分析而是**勇气**（四法则）：
①重将来不重过去（哪个服务于两年后的形态）；
②重机会不重问题（哪个是机会而非止损）；
③自选方向不随波逐流（哪个只是因为同行都在做）；
④目标高远不求安全（哪个带来真正突破而非"过得去"）。

聚焦三律把四法则转为行动：
①一次只推进一项（"我能做这么多难事的秘诀是每次只做一件"）；
②完成后再定下一项（形势已变，不能沿用旧清单）；
③时间留余地不赶尽（唯一确定会发生的是意外，而意外几乎从不带来惊喜）。

此外还有一个**压力画像**自检：压力总是偏爱
"内部 > 外部、往事 > 未来、危机 > 机会、直观 > 真实、紧急 > 有意义"，
让你优先做错事。在排程前问"如果没压力我会怎么排"。

## A1 — 书中的应用 (Past Application)

### 案例 1：莫扎特的多任务反例
- **问题**：要打破"我比较擅长并行"的自我豁免。
- **方法论的使用**：德鲁克用莫扎特——有史以来最伟大的多任务天才——作反例。
  即使是莫扎特，"能同时做好三件大事的人也没有几个"。
- **结论**：能同时做好多件事的人是少数天才；普通人宣称"能并行"是自我欺骗。
- **结果**：普通人必须严格一次只做一件事。

### 案例 2：四勇气法则的实践
- **问题**：管理者面对多任务时难以决策。
- **方法论的使用**：德鲁克指出排序不是分析活——分析只能列出选项，
  选择需要勇气。四法则不是分析工具而是勇气方向。
- **结论**：管理者必须训练自己在排序时"敢于说不"。
- **结果**：重要的事才被做，机会而非问题被优先。

## E — 可执行步骤 (Execution)

### 第一步：列出候选任务清单

- 做法：把所有"接下来 12 个月要做的事"列出来——不分大小。
- 完成标准：清单完整，包含隐性任务（"维持现状""回应客户"）。
- 判停条件：清单有遗漏 → 提示：遗漏的任务在压力下会反客为主。

### 第二步：对每个任务做四勇气法则

- 做法：对每个任务问四问：
  - **重将来**：此项是否服务于两年后组织的形态？
  - **重机会**：此项是机会还是止损？
  - **自选方向**：此项是因为我们想做，还是同行都在做？
  - **目标高远**：此项会带来真正突破，还是"过得去"？
  评分 0-4；高分优先。
- 完成标准：每个任务有 4 项评分。
- 判停条件：用户给出所有任务接近分数 → 提示：评分无差异 = 评分尺度问题，
  需要重新校准。

### 第三步：划分"优先"与"延迟"两堆

- 做法：把任务分为**优先**（12 个月内必须做）与**延迟**（12 个月内明确不做）。
  - 优先：4-7 项（多了则违背"一次只做一件"）。
  - 延迟：其余所有——并**公开**写出"本季度不做"。
- 完成标准：两堆各自明确；延迟清单公开。
- 判停条件：用户把"等"和"再做"放进延迟清单 → 提示：
  "等"不是延迟——延迟是**主动选择本季度不做**。

### 第四步：压力画像自检

- 做法：检查当前排序是否被压力扭曲：
  - 是否过度选了内部事务？是否忽视外部机会？
  - 是否过度选了往事延续？是否忽视未来方向？
  - 是否过度选了危机？是否忽视机会？
  - 是否过度选了直观感觉？是否忽视了真实证据？
  - 是否过度选了紧急？是否忽视了有意义？
  若被压力扭曲，回到第二步重新排序。
- 完成标准：每个压力维度有自检结果。
- 判停条件：用户认为"压力本来就是决策依据" → 提示：压力有系统性偏见，
  不是中性信号——这是本 skill 的核心反直觉。

### 第五步：聚焦三律——执行约束

- 做法：执行期间遵守：
  - **一次只推进一项**：同时推进多项 → 每项都做不完。
  - **完成后重新评估**：完成一项后回到第一步/第二步，**不沿用旧清单**。
  - **时间留余地**：排程留 20-30% 余量（意外几乎从不带来惊喜）。
- 完成标准：每项任务有开始/结束标记；排程有余量。
- 判停条件：用户排程无余量 → 提示：无余量意味着每项意外都是危机。

### 第六步：防"再研究研究"

- 做法：识别清单中"还需要再研究/再观察"的项目——
  这些不是任务，是**逃避**。问"再研究一次会有什么新发现"，答不上就砍。
- 完成标准：清单中无"再研究"作为任务项。
- 判停条件：用户认为"再观察是稳妥" → 提示：稳妥是"没决定"的别名。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **紧急危机处置**：救火不适用本 skill——所有可调动的资源都该上。
- **纯事务性待办**：回邮件、订会议室等不属本 skill 范畴。
- **已确定的任务执行**：本 skill 是规划/排序，不是执行细节。
- **合规/法律任务**：不能用"勇气"取舍。

### 失败模式（决策出错的早期信号）

- **只列优先级没列延迟任务**：典型"两头下注"——每个都做一点，
  每个都没做完。
- **排序被压力驱动**：被紧急邮件牵着走，让危机成为优先。
- **"两头下注"**：每个项目都投 50% 资源 → 每个项目都成功不了。
- **每件做一点**：典型的"看起来很忙"——结果是每个都没完成。
- **不重新评估就延用旧清单**：形势已变但清单没变 → 与机会失之交臂。
- **无余量排程**：每次意外都是危机。
- **以"再研究研究"替代决策**：这是延后决策的最常见借口。

### 时代局限与作者盲点

- **"勇气"是不可操作项**：本 skill 在 E 段四法则依赖"敢于说不"的勇气，
  这是不可教的——但可设置结构性替代：例如"延迟清单是否已公开写出"
  才是可观察的判据，阶段 2 在 E 段给出可观察的替代判据。
- **1967 年的"管理者"多指工业时代的中高层**：当代大量知识工作者是
  个人贡献者（IC）——本 skill 对 IC 同样适用，但"延迟任务"的概念需重新校准：
  IC 的延迟任务可能是"不接某些需求""不开某些会"。
- **德鲁克的样本偏向大型组织**：小团队/创业公司的"优先级"颗粒度更细，
  本 skill 适用但需调整——例如"延迟任务"可扩展为"未做的非紧急事务"。
- **压力画像与现代"敏捷"思维**：敏捷/OKR 强调"快速迭代、拥抱变化"，
  与本 skill 的"重新评估后再定下一项"看似一致，但敏捷鼓励"边走边调"，
  本 skill 更强调"完成一项后整体重排"——颗粒度差异需注意。

### 易混淆方法

- 与"时间管理四象限"：四象限关心"紧急/重要"两个维度；
  本 skill 关心"机会/问题/将来/过去"等更结构化的视角。
- 与"敏捷/Sprint 规划"：Sprint 关心短迭代；本 skill 关心更长周期的取舍。
- 与"重要紧急矩阵（Eisenhower）"：本 skill 的四法则更结构化（重将来、重机会等），
  而 Eisenhower 矩阵更简明。两者可配合。
