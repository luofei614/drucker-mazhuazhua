# 观点检验与衡量标准替换（+ 走出去现场调查）

## R — 原文 (Reading)

> 决策不是从事实开始的，而是从观点开始的。
> ……事实是被相关性标准（relevance）挑选出来的。
> ……观点必须经受事实的检验，否则就是未经检验的假设；
> 但观点本身要被消除，是错的——一个人在某个领域从业多年之后，
> 应该有自己的观点，没有观点说明不善观察、头脑愚钝。
>
> — 德鲁克，第7章 有效的决策

> 既然我们现在要做一个新决策，这通常意味着我们原本的衡量标准已经丧失相关性。
> ……如果唯一衡量标准只能说是/否，就说明思路封闭；
> 而只考虑一个标准，说明思路狭窄。
>
> — 德鲁克，第7章 有效的决策

> 报告用处不大……亲临现场是唯一可靠的反馈。
>
> — 德鲁克，第6章 决策的要素

## I — 方法论骨架 (Interpretation)

"决策要基于事实"是几乎所有聪明人都会说的话。德鲁克从认识论层面否定它——
**事实不是现成摆着的，是被相关性标准挑出来的**。
在物理学里"味道"不是事实，在烹饪里它是至关重要的事实。
所以"决策要基于事实"在执行上是错的：应该先定**相关性标准**，再收集**事实**。

既然要作新决策，旧衡量标准通常已丧失相关性——这是**衡量标准替换**的核心论点。
但**警惕平均值**：平均值掩盖分布，事故集中在一两个岗位、旷工集中在某个部门、
病假集中在少数人群——按平均值采取的"全厂行动"反而让事情更糟。

决策从观点开始（未经检验的假设），但**要检验不是消灭**——
观点要被事实检验，但观点本身要被消灭是错的。
一个在某个领域从业多年的人应该有自己的观点，没有观点说明不善观察。

最后是**现场调查**：报告用处不大，亲临现场是唯一可靠的反馈。
决策者越能拿到抽象信息（今天是有 BI/数据中台），就越容易脱离现场，
越需要刻意走出去。

## A1 — 书中的应用 (Past Application)

### 案例 1：麦克纳马拉的 4% 与 90%
- **问题**：麦克纳马拉任国防部长时用统计指标管理国防——
  4% 的飞行员贡献了 90% 的空对空击落。
- **方法论的使用**：他把飞行员按"击落数"分级——衡量标准改变了。
  旧标准（飞行小时数）已丧失相关性；新标准（击落数）揭示真实分布。
- **结论**：相关性标准改变 = 决策基础改变。
- **结果**：空军训练与战术调整。

### 案例 2：营长去士兵食堂打菜
- **问题**：决策者需要知道"士兵吃什么"。
- **方法论的使用**：营长从士兵食堂的锅里打菜尝一尝——
  不是看报告，是亲临现场。
- **结论**：报告被组织相关性标准过滤；现场反馈唯一可靠。
- **结果**：营长知道真实情况。

### 案例 3：信息失灵（ch02）
- **问题**：总部给生产部门的是"平均值"，生产部门要的是"范围与极值"。
- **方法论的使用**：信息的相关性标准没匹配——总部用"平均值"组织信息，
  生产部门需要"范围"决策。
- **结论**：信息失灵不是"信息不足"——是"信息标准错"。

## E — 可执行步骤 (Execution)

### 第一步：明确决策本身

- 做法：用一句话写明本次决策是什么。
- 完成标准：决策明确。
- 判停条件：用户没有明确决策 → 提示：没有决策就没有事实检验对象。

### 第二步：识别决策依据的观点

- 做法：列出本决策**所基于的观点**——不是事实，而是观点（未经检验的假设）。
  - 例："新客户会喜欢这个功能"（观点）。
  - 不是"80% 客户喜欢这个功能"（事实）。
- 完成标准：列出至少 3 条观点。
- 判停条件：用户把所有"决策依据"都列为事实 → 提示：
  本 skill 的核心反直觉是"决策基于观点"——若用户看不出观点，
  说明被事实表象迷惑。

### 第三步：为每条观点定相关性标准

- 做法：对每条观点问"事实必须是怎样的，这个观点才站得住脚"——
  - 例：观点"新客户会喜欢这个功能"。
  - 相关性标准：客户必须能在 30 秒内找到入口；点击率 ≥ 15%；
    留存率 ≥ 30% 持续 3 个月。
- 完成标准：每条观点有可衡量的相关性标准。
- 判停条件：用户给不出相关性标准 → 提示：没有相关性标准 = 无法检验。

### 第四步：收集事实并对照相关性标准

- 做法：按相关性标准收集事实——
  - 不是"先有事实再决策"，而是"先有标准再收集"。
  - 警惕只收集支持既有结论的事实（确认偏差）。
- 完成标准：每条观点有基于相关性标准的事实回答。
- 判停条件：用户拒绝收集 → 提示：相关性标准是决策的镜子——
  不收集 = 不检验。

### 第五步：识别衡量标准的相关性丧失

- 做法：自检当前衡量标准——
  - 衡量标准是否还是新决策的相关指标？
  - 衡量标准是平均数还是范围？
  - 是否同时考察多种衡量方案？
- 完成标准：明确写出"当前衡量标准是否仍相关"。
- 判停条件：用户认为"老标准还能用" → 提示：
  既然要作新决策，旧标准通常已丧失相关性——这是本 skill 的核心论点。

### 第六步：现场调查

- 做法：决策者必须走出办公室——
  - 去一线 / 客户现场 / 供应商现场。
  - 用五感（看、听、问、触、尝）替代报告。
  - 反复现场调查，避免一次调查就下结论。
- 完成标准：决策者本人亲临现场至少一次。
- 判停条件：用户认为"代我去就行" → 提示：
  本 skill 的核心是"亲临现场"——代去 = 报告。

### 第七步：决策与跟踪

- 做法：基于相关性标准 + 现场调查事实做决策——
  - 决策本身有边界条件（参见 `drucker-boundary-conditions`）。
  - 决策有激励同步（参见 `drucker-decision-to-action`）。
- 完成标准：决策基于检验过的观点 + 相关性标准。
- 判停条件：用户跳过相关性标准 → 提示：决策基础未检验。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **纯一次性事件**：不需要"决策基础检验"。
- **纯技术性诊断**：有客观标准（如医学诊断、工程故障）——
  本 skill 关心的是**决策**，不是诊断。
- **已被反复验证的决策**：过去 N 次都做对的决策——不必每次都重新检验。

### 失败模式（决策出错的早期信号）

- **跳过观点识别**：把所有"决策依据"都当事实——失去本 skill 的核心。
- **无相关性标准就收集事实**：收集了一堆无意义数据。
- **只收集支持既有结论的事实**：确认偏差——决策看似基于事实，
  实际是自证预言。
- **老衡量标准仍在用**：既然要作新决策，旧标准通常已丧失相关性。
- **平均值掩盖分布**：按平均值采取的"全厂行动"反而让事情更糟。
- **代我去现场**：亲临现场不可代理。
- **不复盘**：决策基础无后续检验。

### 时代局限与作者盲点

- **1967 年的"事实"由人工收集**：当代大量事实由 BI/数据中台/AI 收集——
  这些系统的"事实"也是被相关性标准挑出来的，但被工具的客观外观掩盖。
  本 skill 的"警惕平均值""相关性标准替换"在数据中台时代更重要。
- **"亲临现场"的现代化扩展**：当代"现场"可能包括：
  - 客户实际使用产品的视频回放（替代当面观察）。
  - 用户访谈录音与社区反馈（替代"听客户说"）。
  - 一线工具使用日志（替代"看他们怎么干活"）。
  本 skill 的"现场"概念需扩展，但"亲临"原则不变。
- **"决策基于观点"在数据驱动决策中的延伸**：
  当代决策常被表述为"数据驱动"——但"数据驱动"实质上仍是"观点驱动"
  （被相关性标准挑出来的数据）。本 skill 在当代被误读的风险高——
  必须明确"观点"不是"主观随意"，而是"未经检验的假设"。

### 易混淆方法

- 与"批判性思维"：批判性思维是个人能力；本 skill 是决策基础管理。
- 与"假设驱动开发 / Design of Experiments"：DoE 关心实验设计；本 skill 关心
  决策基础检验。
- 与"用户研究 / 用户访谈"：用户研究关心用户需求；本 skill 关心决策反馈。
