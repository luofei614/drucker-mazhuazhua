# 决策转化行动四问（+ 衡量与激励同步）

## R — 原文 (Reading)

> 决策在"分解成具体工作"之前，"顶多可以称之为良好的愿望"。
>
> — 德鲁克，第6章 决策的要素

> 一个决策如果要求改变行为、习惯或态度，那么它就必须包含三项配套变更：
> ①衡量手段必须与新决策匹配；②绩效标准必须与新决策匹配；
> ③激励手段必须与新决策匹配。否则，决策会被悄悄废弃——
> 不是因为有人反对，而是因为没有人会真正按新决策行动。
>
> — 德鲁克，第6章 决策的要素

## I — 方法论骨架 (Interpretation)

决策与执行不是两个阶段——决策**必须**包含行动安排，否则"顶多算良好的愿望"。
"宣布决策"不等于"决策生效"。

四问是把决策分解为行动的标准问：
①**谁必须知情**——这是最易漏的问，且它问的不是"谁负责干"，
  而是"**谁会因为不知道而继续按旧规则做事**"。
②**必须采取哪些行动**——具体到可执行。
③**谁负责**——明确到岗位或人。
④**行动必须长什么样才能让负责人施行**——与执行者的能力匹配。

四问之后还有一个**激励同步**检查：
决策若要求改变行为/习惯/态度，衡量手段、绩效标准、激励**必须同步改**——
否则决策会被悄悄废弃。不是因为有人反对，而是因为没有人会真正按新决策行动
（他们按旧规则行动更划算）。

## A1 — 书中的应用 (Past Application)

### 案例 1：机床厂商采购员（反例）
- **问题**：机床厂商决定把销售重点从大公司转向中小企业。
- **方法论的使用**：决策者忘了问"谁必须知情"——
  采购员继续按"销量比例"向大公司备货。
- **结论**：仓库积压了够用 8-10 年的零件，新决策在执行端失效。
- **结果**：决策看似有效，实际未落地。

### 案例 2：韦尔把"服务绩效"变成经理的考核标准
- **问题**：韦尔任贝尔总裁时，决定把"服务"作为公司战略核心。
- **方法论的使用**：他把"服务绩效"变成经理的考核标准——
  衡量手段、绩效标准、激励全部同步改。
- **结论**：决策落到每个经理的考核表里——执行自然发生。
- **结果**：贝尔成功转型为系统服务公司。

### 案例 3：西非化工
- **问题**：某化工企业在西非市场销售失败。
- **方法论的使用**：决策者派了"会说英语的欧洲人"做销售——但他们不懂当地文化。
  应该派懂当地文化的人，且衡量指标应改"市场份额"而非"销售额"。
- **结论**：决策者的行动安排与执行者的能力不匹配。
- **结果**：决策未能落地。

## E — 可执行步骤 (Execution)

### 第一步：写明决策本身

- 做法：用一句话写明本次决策是什么。
- 完成标准：决策明确。
- 判停条件：用户没有明确决策 → 提示：没有决策就没有行动。

### 第二步：四问启动

- 做法：四问逐一回答：
  - **问 1：谁必须知情？**
    - 列出会因为不知道而继续按旧规则做事的所有人/岗位。
    - 不仅包括"谁负责干"，更包括"谁会因为不知道而继续按旧规则做事"。
  - **问 2：必须采取哪些行动？**
    - 列出具体行动（含动作、对象、产出）。
  - **问 3：谁负责？**
    - 每个行动明确到岗位或人。
  - **问 4：行动必须长什么样才能让负责人施行？**
    - 检查负责人是否有能力（培训/工具/支持）。
    - 检查行动是否与现有工作流程衔接。
- 完成标准：四问都有具体答案。
- 判停条件：四问任一是模糊答案 → 提示：模糊答案 = 决策未完成。

### 第三步：识别"激励/衡量同步"信号

- 做法：检查决策是否要求改变行为/习惯/态度——
  - 若"是" → 必须包含三项配套变更：衡量手段、绩效标准、激励手段。
  - 若"否" → 仅进入第四步。
- 完成标准：明确写出三项配套变更。
- 判停条件：用户认为"激励同步是另一件事" → 提示：
  本 skill 的核心反直觉是"激励同步不是另一件事，而是决策的一部分"。

### 第四步：沟通与培训

- 做法：把四问 + 激励同步的结果向下沟通——
  - 告知知情清单上的所有人。
  - 提供必要培训（针对负责人能力的差距）。
- 完成标准：每个知情人都收到了明确信息；每个责任人都接受了必要培训。
- 判停条件：用户认为"发邮件即可" → 提示：本 skill 关心的是"被理解"，
  不是"被发送"——发邮件 ≠ 知情。

### 第五步：执行跟踪

- 做法：建立定期跟踪机制——
  - 决策执行进度（行动完成情况）。
  - 衡量手段的输出。
  - 激励是否兑现。
- 完成标准：跟踪机制建立，且有明确报告频率。
- 判停条件：用户认为"开始执行即可" → 提示：决策的有效性
  在于执行，而执行需要跟踪——本 skill 关心的不是"开始"，
  而是"持续"。

### 第六步：复盘与修正

- 做法：决策执行 3-6 个月后复盘——
  - 决策目标是否达成？
  - 行动是否到位？
  - 激励同步是否起作用？
  若有偏差 → 回到第二步/第三步修正。
- 完成标准：复盘记录完成。
- 判停条件：用户认为"决策结束了" → 提示：决策的有效性
  不在于"被宣布"，而在于"被执行 + 持续被执行"。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **纯一次性事务决策**：不需要完整四问——直接执行即可。
- **紧急危机处置**：救火期间不需要完整激励同步。
- **已被法规/合同要求的动作**：本 skill 不适用。

### 失败模式（决策出错的早期信号）

- **跳过"谁必须知情"**：决策者漏掉了"会按旧规则继续做事"的人——
  这是四问里最易漏但代价最大的。
- **行动描述模糊**："提升能力""加强协同"等——不可执行的描述。
- **无人负责**：行动有清单但无人负责——责任分散。
- **负责人能力不匹配**：要求他们做不会的事——决策落空。
- **激励不同步**：决策要求新行为，但衡量与激励仍按旧规则——
  这是决策被悄悄废弃的最常见原因。
- **"发邮件"代替沟通**：被发送 ≠ 被理解。
- **无跟踪机制**：开始执行后无跟踪——决策慢慢失效。
- **不复盘**：决策无闭环——下次类似决策无学习依据。

### 时代局限与作者盲点

- **1967 年的"决策执行"偏组织内**：当代决策常需跨组织执行
  （供应链、生态系统、开源社区），激励同步的边界更模糊——本 skill 的
  同步机制需扩展到组织外。
- **"激励同步"在知识工作中很难量化**：体力劳动可以用计件同步激励，
  知识工作的"激励"更多是文化/认可/成长——本 skill 在知识工作场景下
  需补充"非物质激励"维度。
- **"行动必须长什么样才能让负责人施行"的现代扩展**：
  当代许多决策的执行者是人机混合（AI 工具 + 人），
  决策执行的"能力匹配"需考虑 AI 工具的可得性。

### 易混淆方法

- 与"项目管理"：项目管理关心项目执行；本 skill 关心决策转化行动。
- 与"OKR / KPI"：OKR/KPI 关心目标管理；本 skill 关心决策落地。
- 与"执行力管理"：执行力管理关心个人能力；本 skill 关心系统安排。
