# 用人所长四法则（职位客观 / 不因人设岗 / 有高峰必有深谷 / 正直一票否决）

## R — 原文 (Reading)

> 有效管理者从来不问："他跟我的关系怎么样？"他们问的是："这个人可以做出什么贡献？"
> ……创建一流管理者团队的人，往往不会跟直接同事和下属建立特别亲密的关系。
> 按照能力而不是自己的喜好挑选人，追求的是绩效，而不是顺从。
>
> — 德鲁克，第4章 让长处富有成效

> 任何一个职位，如果连续挫败了两三个人，而他们在之前的职位上都干得很出色，
> 那就必须认定这是一个常人无法胜任的职位，必须重新设计。
>
> — 德鲁克，第4章 让长处富有成效

> 只有在这一个方面，只要存在短处就应当做出否决——那就是"正直"。
>
> — 德鲁克，第4章 让长处富有成效

## I — 方法论骨架 (Interpretation)

德鲁克把"用人"完全翻转为以任务和长处为中心：不是"谁好就用谁"，而是"这个职位
要交付什么 → 谁在相关领域有突出长处 → 用长处的判据选人 → 用职位安排消除短处"。
四法则是一个连贯程序，不能拆开执行。

**第一法则：职位客观由任务决定，绝不因人设岗。**
职位不是上帝造的，是容易犯错误的人设计的；组织是一个互相咬合的齿轮系统，
动一个会波及全体。因人设岗的隐性代价是"基调从'什么是正确的'滑向'谁是正确的'"，
结果是徇私与顺从。

**第二法则：用人三问。**
①他在某个**重要领域**有长处吗？
②这个长处与**这项任务**相关吗？
③若该长处发挥到极致，能产生**重大成果**吗？
三个"是"才用。两个"是"勉强可用。一个"是"以下不用。

**第三法则：有高峰就有深谷。**
人把全部资源倾注到一个领域才能卓越，代价是其他领域偏废。
寻找"完人"等于开方子寻找平庸（林肯的前三任北方军总司令就是这类）。
短处的处置靠职位设计（让该职位不要求那个能力），不靠纠错或培训。

**唯一否决项：正直。**
判定方式非常具体——"如果我有儿女，愿意送到他手下去工作吗"。
理由：有魄力但品德败坏的上级是组织里最具破坏力的东西，
因为会成为聪明年轻人的楷模。这条是**唯一**针对短处的判据。

## A1 — 书中的应用 (Past Application)

### 案例 1：林肯用格兰特
- **问题**：林肯先后任命三任北方军总司令，皆因追求"完人"而失败；战事僵滞。
- **方法论的使用**：林肯转而接受"有高峰就有深谷"，任命嗜酒的格兰特将军。
  他知道格兰特有严重短处，但格兰特在"指挥作战"这一任务上具备无与伦比的长处，
  且这是此刻北方最需要的成果。
- **结论**：启用格兰特。短处（嗜酒）由后续安排（不让其饮酒场合）消除，
  不作为否决理由。
- **结果**：李将军投降，北方获胜。短处的处置完全交由职位与制度安排。

### 案例 2：马歇尔的"长处型考评"
- **问题**：马歇尔任陆军参谋长时面对众多军官，要识别并提拔真正能打仗的人。
- **方法论的使用**：他不用"找缺点"的考评（因考评工具天生是找病的），
  而是用"四问"的长处清单。
- **结论**：识别出一批卓越军官，包含巴顿等性格鲜明、短处明显但长处致命的人。
- **结果**：盟军在二战中取胜，且马歇尔自己保持"团队中唯一的正派人"——靠任务为重心维持距离。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写 JD 或评估简历时，反复纠结于"某方面明显不行"的候选人。
2. 组建新团队（项目组、新业务线、合伙制小组）。
3. 决定提拔或解雇某人——尤其是"业绩好但合作者嫌难相处"的经典困境。
4. JD 出现"全面""成熟""没有明显短板""综合素质好"等词（已可判定为筛选平庸）。
5. 因人设岗的诱惑出现（"要不专门为他设个新岗"）。

### 语言信号（用户的话里出现这些就应激活）

- "这个人全面不全面" / "综合素质怎么样"
- "短板太明显了，敢不敢用"
- "为 XX 专门设一个岗"
- "他和团队气场合不合"
- "人岗匹配" / "匹配度"
- hire for strengths / how to hire / staff by strengths / weaknesses outweigh strengths

### 与相邻 skill 的区分

- 与 `drucker-job-redesign` 的区别：本 skill 解决"如何选人"——同一职位、同一任务下选哪个；
  `drucker-job-redesign` 解决"职位本身是否需要重设计"——已经连续挫败两三个在原岗位表现出色的人，
  就该怀疑是职位设计错了，**不再在选人上加力**。
- 与 `drucker-strength-appraisal` 的区别：本 skill 是**任用前的判断**（用于选/用）；
  `drucker-strength-appraisal` 是**任用中的持续考评**（用于识别长处、规划成长、决定保留/淘汰）。
- 与 `drucker-indispensable-person` 的区别：本 skill 看"该不该用"，那个 skill 看"已经在岗的某个人是不是组织病灶"。

## E — 可执行步骤 (Execution)

### 第一步：明确"这个职位要交付什么"

- 做法：用三句话回答"这个职位是为解决什么外部问题而设的"。
  若答不上来 → 职位尚未客观化，回到 JD 设计层。
- 完成标准：能写出"职位 × 任务 × 关键成果"三段；JD 里没有"全面""成熟""综合素质"。
- 判停条件：用户想用"好管理就是人尽其才""为人才量身定做舞台"为因人设岗辩护 →
  停止本步，明确告知：因人设岗"几乎必然导致徇私和顺从"，基调会从
  "什么是正确的"滑向"谁是正确的"。

### 第二步：用"用人三问"评估每位候选人

- 做法：对每位候选人逐条问：
  - **问 1（长处）**：在某个领域表现卓越吗？有可指认的事实证据吗？
  - **问 2（相关）**：这个长处跟"第一步"写出的关键任务**直接相关**吗？
  - **问 3（成果）**：若这个长处发挥到极致，能产生**重大成果**吗？
  - 三"是" → 用；两"是" → 可用但需要补强；三"是"以下 → 不用。
- 完成标准：每位候选人有三问的明确答案；不允许"差不多"作为答案。
- 判停条件：用户提出"短板否决"理由 → 重新检视第一步是否写错了任务（如果是任务要求，就不是短板；如果是无关任务，砍掉这一项任务本身即可）。

### 第三步：识别高峰对应的深谷

- 做法：列出候选人的**已确认**短处（不是猜测，是可观察）。
  对每个短处问：这个短处能否通过**职位安排**（协作接口、配 BP、汇报路径）变得无关紧要？
  - 可以 → 接受短处，继续。
  - 不可以（短处是任务核心要求） → 回到第二步，重新选人。
- 完成标准：每位候选人的短处有一项对应的"职位/协作层消除手段"。
- 判停条件：用户提出"应该培训他补短" → 停止本步，明确告知：
  训练短处是低效的（人把全部资源倾注到长处，代价就是其他领域偏废）。

### 第四步：正直一票否决

- 做法：用具体测试取代抽象道德争论："如果我有儿女，愿意送到他手下去工作吗？"
  - 愿意 → 进入最终候选。
  - 不愿意 → 否决，不论业绩多好。
- 完成标准：每个最终候选人有"是否愿意"的明确判断；
  不是"看具体场景""需要再观察"——这两个答案都等于不愿意。
- 判停条件：用户认为"能力强就能弥补品德" → 停止本步，明确告知：
  有魄力但品德败坏的上级是组织里最具破坏力的东西，因为会成为聪明年轻人的楷模。
  能力越大破坏越系统化。

### 第五步：公示决策与岗位依据

- 做法：把录用决策与"该职位最关键的成果/任务"挂钩公示——
  写明"录用此人是因为他能在 X 任务上产生 Y 成果"。
- 完成标准：决策理由是**任务驱动**的，不是"这个人好不好"的个人评价。
- 判停条件：用户给出"他和团队气场合得来""聊得来"作为理由 → 停止本步，
  明确告知：这是把人际和谐当作目的而不是手段，与绩效导向反向。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **纯人事操作**：薪酬包、合同条款、入离职流程——本 skill 不管人事手续。
- **纯文化建设**：团队氛围、信任、协作风格本身不是本 skill 关心的结果。
  本 skill 关心的是"以任务为重心的人际秩序"（一种工具，不是目的）。
- **可自由支配时间趋近于零的岗**：急救、实时响应类岗位
  （同 `drucker-time-log-consolidate` 边界）——选人仍按四法则，但第三步"集中整块"不适用。

### 失败模式（决策出错的早期信号）

- **因人设岗**：有人提出"为了留住 XX，给他专门设个位子"——基调已从
  "什么是正确的"滑向"谁是正确的"。
- **寻找完人**：JD 反复要求"全面""成熟""没有明显短板"——这是开方子寻找平庸。
- **凭气场用人**：决策理由是"聊得来""气场合""看着舒服"——人际和谐被当成目的。
- **短板否决**：因"沟通弱""不擅汇报"否决了长处致命的候选人——
  这些通常应通过职位安排而非人选淘汰处理。
- **能力 = 德性**：认为"能力强就能弥补品德"——
  这会让有魄力但品德败坏者成为聪明年轻人的楷模，破坏最系统性。

### 时代局限与作者盲点（必须坦承）

- **"有意与同事保持距离"**：1967 年德鲁克写作时，组织心理学尚未发展出
  "心理安全感"概念。距离的原始功能是保证多样性（让异见成为可能），
  而非建立冷漠关系。**在现代组织中，距离应通过"以任务为重心"实现**，
  而非"人际疏远"。如果一个团队既强调心理安全又强调本 skill 的距离，
  不是矛盾，而是要求把"距离"翻译成"不要用私交代替绩效判断"。
- **样本偏差**：德鲁克举的案例（林肯、马歇尔、斯隆、罗斯福）几乎清一色
  是 1960 年代男性高层。这一经验无法推广到多元团队、女性领导者、
  远程团队、Z 世代——他们的"距离"与"个性"机制不同。
  应用本 skill 时需自己补足：当候选人是女性、有色人种、年轻一代时，
  "性格是否合适"的判断更易受偏见污染，需要更严格的"长处证据链"。
- **"提高门槛"vs"消除短处"的边界**：本 skill 主张消除短处而非修补，
  但有时短处正是成长方向（如新管理者沟通弱 → 系统培训），
  这与"训练短处是低效"在表面冲突。实际判据：若短处是该职位的核心要求
  → 不通过；若短处是成长方向而非职位要求 → 可通过培训提升，但前提是
  "接受该短处可以无限期不被消除"。

### 易混淆方法

- 与"行为面试法（STAR）"：行为面试问过去行为做未来推断，关心"如何做事"；
  本 skill 问"此人能在什么任务上创造什么成果"，关心"能交付什么"。两者可叠加，
  不要混用——STAR 的"行为维度"会被误读为"全面性"，从而污染用人判断。
- 与"OKR/KPI 体系"：本 skill 关心**人岗匹配**（选人），
  OKR 关心**目标分解**（管人）。即使 OKR 完美，如果人选错了，
  OKR 也救不了。
