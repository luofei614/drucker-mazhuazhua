# 边界条件定义 + 先正确后妥协（半个面包 vs 半个婴儿）

## R — 原文 (Reading)

> 边界条件的定义越是清晰、精确，决策就越有效；反之，决策就越无效。
> ……边界条件的定义本质上是一种研判，而不是单纯的计算或期望。
> ……决策从"正确"的方案开始，而不是从"可接受"的方案开始。
> 决策过程中的妥协必须以"什么是正确的"为基础——只有这样才能产生
> "什么是可接受的妥协"。半块面包仍然是面包，半个婴儿则是尸体。
>
> — 德鲁克，第6章 决策的要素

> 最危险的决策，是那种"假如一切都不出差错"才有可能奏效的决策。
>
> — 德鲁克，第6章 决策的要素

## I — 方法论骨架 (Interpretation)

边界条件是**决策目标的具象化**——不是"做到更好"，而是"达到什么目的、
最低目标、必须满足哪些条件"。边界条件越精确，决策越有效。

但边界条件不是计算出来的，是**冒着风险的研判**——这是反常识的关键。
常见错误是把边界条件当成"需求文档"或"约束列表"做客观推导——
实际上，决策者必须对边界条件本身做判断（"我们要的真是 X 吗"）。

边界条件有三重功能：①指导决策；②检验方案；③**决定何时该放弃**。
这三个功能一体——边界条件一变，决策就要重新评估。

"先正确后妥协"是配套的论证逻辑：先想清楚"什么是正确的"
（假设资源无限、约束不存在，完整解是什么），
再谈可接受的妥协。用"半面包/半婴儿"判据：妥协后是否仍满足边界条件。
半块面包仍是食物（妥协成立），半个婴儿是尸体（妥协不成立）。

最危险的决策形态：**"假如一切都不出差错才有可能奏效的决策"**——
这种决策没有任何容错，差一步就崩盘。

## A1 — 书中的应用 (Past Application)

### 案例 1：史里芬计划 vs 罗斯福银行假日
- **问题**：两种不同边界的决策对比。
- **方法论的使用**：
  - 史里芬计划：一战时德国参谋本部的两线作战计划，前提是"俄国动员慢于法国"——
    这就是边界条件。后来的执行者丢掉了"不得分散部署"这条边界，结果崩盘。
  - 罗斯福银行假日：1933 年的银行假日决策，边界条件清晰（恢复民众对银行的信心），
    即使短期代价大但符合边界条件。
- **结论**：边界条件丢失 vs 严格遵守——两者命运截然不同。

### 案例 2：猪湾事件 vs 纽约时报 48 分钟
- **问题**：两个决策对比。
- **方法论的使用**：
  - 猪湾：1961 年肯尼迪政府入侵古巴，决策的前提是"古巴民众会起义"——
    这条边界条件未经验证就用了，结果崩盘。
  - 纽约时报：48 分钟关闭电厂抢救设备的决策，边界条件清楚（抢救设备），
    决策与边界一致。
- **结论**：错误的边界条件 = 决策越多越糟。

### 案例 3：斯隆的"先告诉他们什么是正确的"
- **问题**：通用汽车的事业部决策。
- **方法论的使用**：斯隆在决策前先告诉事业部"什么是正确的"——
  即先定义完整解，再谈妥协。
- **结论**：妥协必须建立在"正确"的基础上，否则等于绕开决策。
- **结果**：通用的事业部制分权能长期运转。

## E — 可执行步骤 (Execution)

### 第一步：定义边界条件（五问）

- 做法：回答以下五问：
  - **目的 1**：本决策要达到什么目的？
  - **目的 2**：最低目标是什么（最不济到什么程度）？
  - **目的 3**：必须满足哪些条件？
  - **目的 4**：什么情况下应该放弃这个决策？
  - **目的 5**：边界条件之间的本质关系是什么？（互斥？互依？）
- 完成标准：五问都有具体答案；不是"做得更好"这种模糊表述。
- 判停条件：用户写"做得更好""提升效率"等模糊目标 → 提示：
  边界条件必须具体到可衡量——模糊边界 = 任何方案都"差不多"。

### 第二步：识别边界条件的"非常规"性

- 做法：检查边界条件是否是**研判**（judgment）而非计算（calculation）——
  - 决策者必须主动承担判断责任。
  - 边界条件可以争论、修改。
  - 不是单纯的需求列表。
- 完成标准：明确写出"这是研判"。
- 判停条件：用户认为"边界条件客观推导即可" → 提示：
  本 skill 的核心反直觉就是"边界条件是研判，不是计算"。

### 第三步：识别"最危险决策形态"

- 做法：自检——决策是否有任何边界条件是"假如一切都不出差错才有可能奏效"。
  - 若有 → 重新评估（往往需要把这种条件降为"必须满足"或重新定义）。
  - 若无 → 进入第四步。
- 完成标准：明确说明决策不依赖"一切都不出差错"。
- 判停条件：用户认为"所有决策都有风险" → 提示：本 skill 关心的
  是"无容错的决策"——有风险与无容错不同。

### 第四步：先想清楚"什么是正确的"

- 做法：在妥协之前，先定义完整解：
  - 假设没有任何约束（预算、时间、组织阻力），什么是真正正确的方案？
  - 写出完整解。
- 完成标准：完整解明确。
- 判停条件：用户跳过此步直接妥协 → 提示：本 skill 的核心反直觉是
  "正因为妥协不可避免，所以起点才更不能是妥协"。

### 第五步：用"半面包/半婴儿"判据检验妥协

- 做法：每个妥协提案都用此判据——
  - 妥协后是否仍满足边界条件？
  - "半面包仍是面包，半个婴儿是尸体"——这是本质判据。
- 完成标准：每个妥协都通过判据检验。
- 判停条件：用户认为"妥协就是要让步" → 提示：让步如果破坏边界条件，
  就是把婴儿切成两半——必须拒绝。

### 第六步：明确放弃条件

- 做法：写明决策的放弃条件——
  - 触发什么信号 → 立即停止？
  - 谁有权决定放弃？
- 完成标准：放弃条件明确。
- 判停条件：用户认为"开始就要做到底" → 提示：决策的放弃条件
  与开始条件同等重要——没有放弃条件 = 沉没成本绑架。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **纯定性目标**（"做得更好""提升能力"）——不可衡量的目标不是边界条件。
- **无明确可衡量目标**——本 skill 不适用。
- **紧急危机**：救火时没时间做边界条件分析——先把火灭了再说。

### 失败模式（决策出错的早期信号）

- **边界条件模糊**："做得更好""提升效率"——
  模糊边界 = 任何方案都"差不多"。
- **把边界条件当需求列表**：计算而非研判——
  本 skill 关心的核心是研判，不是列举。
- **跳过"什么是正确的"**：直接妥协——
  妥协的起点错了，妥协不会自动变成正确。
- **妥协破坏边界条件**：半面包 vs 半个婴儿判据失败——必须拒绝。
- **无放弃条件**：沉没成本绑架——开始就要做到底。
- **错误边界条件导致系统性失败**：史里芬、猪湾案例——
  边界条件错，决策越用力越糟。
- **决策依赖"一切都不出差错"**：最危险决策形态——无容错。

### 时代局限与作者盲点

- **1967 年的"边界条件"偏工业时代战略决策**：当代"边界条件"更复杂——
  网络效应、生态系统、政策法规、技术成熟度都成为边界条件，且互相关联。
  本 skill 的五问仍适用，但**互依关系**的判断需更强的多变量分析能力。
- **史里芬/猪湾的"研判"高度依赖军事/政治专业判断**：商业/技术决策的
  研判基础更薄，错误边界条件的概率更高——本 skill 不能保证研判正确，
  只能保证"研判的方法论清晰"。
- **"先正确后妥协"在敏捷/Sprint 中被重新定义**：敏捷鼓励"快速迭代、从小做起"——
  与"先想清楚完整解"看似矛盾。但敏捷的"从小"≠ "妥协"——
  "从小"是"用最小可行方案验证完整解"，与本 skill 不矛盾。
  颗粒度差异需注意。
- **"半面包/半婴儿"在数据驱动决策中适用性**：当代大量决策有数据支撑，
  半面包/半婴儿判据仍适用，但需与"统计显著性"等概念配合。

### 易混淆方法

- 与"需求分析"：需求分析关心"需要什么"；本 skill 关心"达到什么目的"。
- 与"目标管理 / OKR"：OKR 关心"如何定目标"；本 skill 关心"如何定义决策边界"。
- 与"多目标优化"：多目标优化关心"如何平衡"；本 skill 关心"如何定义边界"。
