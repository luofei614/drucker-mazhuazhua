# 长处型考评四问（正直为唯一一票否决项）

## R — 原文 (Reading)

> （1）他在哪个方面已经做得很好？（2）所以他可能在哪个方面做得很好？
> （3）他要想充分发挥长处还需要学会哪些东西？（4）如果我有儿女，
> 愿意送到他手下去工作吗？
>
> 良好品格和正直本身并不足以成事，但缺少它们会搞砸一切。
> 因此，只有在这一个方面，只要存在短处就应当做出否决。
>
> — 德鲁克，第4章 让长处富有成效

## I — 方法论骨架 (Interpretation)

德鲁克把考评整个翻转：**不是找问题，而是找长处**。理由直指考评工具的来源——
"临床心理诊断法"，其设计目的是找病（用于评价不健康的人），用于健康人是工具错配。

执行程序有强前置：考评前**先列出期望的重大贡献与对照目标的实绩**——
不写这两项就启动四问，等于在没有参照系的情况下评估。

四问的设计哲学是"由实到潜到成长到否决"的递进：
①问已经做到什么（事实，长处证据）；
②问由此推导可能在哪做得很好（合理推断）；
③问还需学什么才能充分发挥（成长方向，非短处清单）；
④问是否愿意让儿女在他手下工作（唯一的短处否决项）。

非常反常识的是第四问——不是能力、不是情商、不是合群，而是**正直**。
判定方式也非常具体："如果我有儿女，愿意送到他手下去工作吗？"——一个绕开
抽象道德争论的具体测试。理由：有魄力但品德败坏的上级是组织里最具破坏力的
东西，因为会成为聪明年轻人的楷模。能力越大，破坏越系统化。

## A1 — 书中的应用 (Past Application)

### 案例 1：马歇尔将军的长处型考评
- **问题**：马歇尔任陆军参谋长，要识别与提拔能打仗的军官。
- **方法论的使用**：他不用"找缺点"的考评（因为考评工具是诊断工具，
  用于评价健康人是错的），而是用"四问"长处清单。
  对每位军官问"他在哪方面做得很好"，并据此判断他能做什么。
- **结论**：识别出一批卓越军官——其中很多人在"性格"、"表达"、"团队精神"上
  评分极低，但"作战"长处致命。
- **结果**：盟军在二战中取胜。马歇尔的考评方式成为美国陆军传统。

### 案例 2：日本高管的考评哲学
- **问题**：日本大企业早期以终身雇用、年功序列著称，没有西方意义上的考评。
- **方法论的使用**：作者分析这不是管理落后，而是另一种评价方式——
  通过长期观察识别长处与短处，但更聚焦于前者，且不依赖单一时刻的"打分"。
- **结论**：考评不是必须的，但若做，应聚焦长处。
- **结果**：在德鲁克看来，这套做法的核心精神——"先识别长处再配置"——
  与长处型考评一致。

## A2 — 触发场景 (Future Trigger) ★

### 与相邻 skill 的区分

- 与 `drucker-strength-staffing` 的区别：本 skill 是**任用中的持续考评**
  （用于识别长处、规划成长、决定保留/淘汰）；那个 skill 是**任用前的判断**
  （用于选/用）。逻辑链：先用 strength-staffing 选人 → 用本 skill 持续考评
  → 用 indispensable-person 诊断"不可或缺"的异常。
- 与"360 评估"：360 是多角度反馈，关心"他做事的方式"；本 skill 关心"他在哪
  个任务上能产生什么成果"。360 的"行为维度"很容易让"沟通弱""不擅汇报"
  成为否决项——这是误用。
- 与"行为锚定评分法（BARS）"：BARS 关心行为级别与分数；本 skill 关心长处与
  成果。可配合，不混用。

## E — 可执行步骤 (Execution)

### 第一步：前置动作——列期望贡献与对照实绩

- 做法：在启动四问之前，先写出两段：
  - **期望的重大贡献**：本周期对此人期望的关键成果（不是 OKR 全集，是
    3-5 个真正能定义他价值的成果）。
  - **对照目标的实绩**：每个期望贡献对应的实际达成（含证据）。
- 完成标准：每条期望有对应的实绩评估（超额/达标/未达）。
- 判停条件：用户跳过此步直接进入四问 → 停止本 skill，明确告知：
  没有参照系就启动四问，等于盲评。

### 第二步：问 1——"他在哪个方面已经做得很好？"

- 做法：从**事实**出发，列出此人在过去 12-18 个月中可指认的卓越表现。
  不是"他沟通不错"这种抽象评价，而是"他在 X 项目中通过 Y 行动带来 Z 成果"这样的事实链。
- 完成标准：每条"做得很好"有可追溯的事实证据（项目、决策、数据）。
- 判停条件：用户给出"他综合能力很强""素质很好" → 停止本步，明确告知：
  抽象判断不是长处，是公关辞令。

### 第三步：问 2——"所以他可能在哪个方面做得很好？"

- 做法：从问 1 的事实推导**下一步**可迁移的长处。
  - 若他在小客户上销售极强 → 可能在中等客户上也可做强。
  - 若他在稳定环境中出色 → 在剧烈变化环境中表现存疑（不要假设可迁移）。
- 完成标准：每条推断有"为什么可迁移"的逻辑链，而非"应该也可以"。
- 判停条件：用户提出"他应该可以做 X" → 停止本步，明确告知：除非有事实链，
  "应该"是期望不是评估。

### 第四步：问 3——"他要想充分发挥长处还需要学会哪些东西？"

- 做法：列出**成长方向**——不是"改进哪些短处"，而是"为了把长处用得更好，
  他需要发展哪些能力"。
  - 例：长处是技术判断力 → 成长方向可能是"如何向非技术听众解释"。
- 完成标准：每条成长方向都服务于**现有长处的放大**，不是修补无关的短处。
- 判停条件：用户列出"沟通弱、不擅汇报、PPT 做得差" → 停止本步，
  明确告知：这些是该职位不要求的能力，应通过职位安排让它们无关紧要，
  而非塞进"改进计划"。

### 第五步：问 4——"如果我有儿女，愿意送到他手下去工作吗？"

- 做法：用这个具体测试取代抽象道德判断：
  - 愿意 → 继续。
  - 不愿意 → 一票否决，不论前几问的答案多漂亮。
- 完成标准：决策者明确说出"愿意/不愿意"。
- 判停条件：用户给出"需要再观察""看具体场景" → 停止本步，明确告知：
  这两个答案都等于不愿意——若你不愿意让他教你的孩子，你就该不愿让他教
  你的下属。

### 第六步：把"难相处"作为**局限**而非短处处理

- 做法：若此人"难相处"但问 4 为愿意 → 通过职位安排让"难相处"无关紧要：
  - 配 BP / 项目经理负责跨部门沟通。
  - 把他放到不需大量协作的岗位上。
  - 把他的汇报与协作收敛到书面接口。
- 完成标准："难相处"有一项对应的"职位/协作层消除手段"。
- 判停条件：用户提出"他应该改改性子" → 停止本步，
  明确告知：性格是天生与人格的，不是改进项。

## B — 边界与失败模式 (Boundary)

### 不适用场景 / 反例（违反任一即停用本 skill）

- **纯薪酬调整**：调薪与本 skill 关心的长处/诚实问题无关。
- **劳动合同法合规**：解雇合法性流程不在本 skill 范畴。
- **强制分布排名**：要求必须评出 10% 末位等强制分布场景，与长处型考评哲学根本冲突。
- **刚入职 < 6 个月**：观察期不足。

### 失败模式（决策出错的早期信号）

- **跳过前置动作**：没写期望贡献与对照实绩就启动四问 → 盲评。
- **抽象判断替代事实**："他综合能力很强" → 不是长处。
- **把"改进计划"作为产出**：考评表里"改进建议"占主导 → 工具错配（找病的工具
  用于健康人）。
- **性格被作为短处**："沟通弱、不擅汇报"出现在改进项 → 应通过职位安排解决。
- **抽象道德判断**：用"他人品有问题"否决，但说不出"愿不愿让儿女去他手下"
  → 抽象道德判断不构成否决证据。
- **"需要再观察"作为缓兵之计**：对问 4 的答案 → 等于不愿意，立即否决。
- **"业绩好就能弥补品德"**：违反问 4 的功能——品德败坏的楷模效应是
  系统性的破坏。

### 时代局限与作者盲点

- **"愿意把儿女送去他手下"的判定依赖评价者的直觉与立场**：
  1967 年德鲁克写作时，主流管理者是白人男性，判定标准难免带有同质化偏好。
  在多元化团队中，需用更结构化的"行为证据"补强（如"他在压力下是否对下属
  说真话""他是否把功劳归于他人"），不能只依赖个人直觉。
- **考评工具的历史包袱**：当前主流绩效工具（BARS、360、OKR 评分）多数
  源自临床心理/行为主义传统，与长处型考评不直接兼容。本 skill 不强求
  抛弃现有工具，但要求**四问**作为最终决策的输入。
- **"儿女测试"在 D&I 语境下的脆弱性**：在性别歧视、性骚扰问题被广泛认识
  的今天，"儿女测试"是一种便利的"信任度"测试，但在跨文化团队中
  可能被误读为"家长式权威"。需明确：测试的是"对下属的安全"，不是
  "对儿女的喜爱"。

### 易混淆方法

- 与"360 度反馈"：360 关心"做事的方式"；本 skill 关心"做事的能力"。
- 与"行为面试法（STAR）"：STAR 关心过去行为预测未来表现；本 skill 关心
  "长处可放大到哪个方向"。
- 与"九宫格人才盘点"：九宫格关心"绩效 + 潜力"两个维度；本 skill 只关心
  "长处 + 正直"，没有潜力维。
