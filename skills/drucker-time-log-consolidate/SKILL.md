# 时间实录与整块集中

## R — 原文 (Reading)

> 依我的观察，有效管理者不是从工作任务入手，而是从时间入手。首先做的不是制订工作计划，而是弄清楚自己的时间都花在了什么地方。然后，他们努力管好自己的时间，拒绝那些不会带来成效的时间要求。最后，他们把自己的"可自由支配时间"集中成尽量大块的连续时段。三步法包括：记录时间；管理时间；集中时间。
>
> — 德鲁克，第2章 认识你的时间

## I — 方法论骨架 (Interpretation)

这套方法的起点不是"怎么把事做完"，而是"时间到底去哪了"。德鲁克认为，时间对管理者有三重特殊性：供给弹性为零（再多钱也买不到）、无法存储（今天不用的时间不会留到明天）、无法替代（没有任何资源能顶替它）。而人对自己时间去向的感知在生理上就不可靠——所以任何关于"我的时间花在哪"的判断，都不得以记忆为依据。

三步的顺序不能颠倒：**先记录，再管理，最后集中**。多数人跳过第一步直接去学"高效技巧"，等于在没有测量数据的情况下优化系统。

- **记录**：必须实时记（事件发生时记，不是事后补），连续三四周，每年至少做两次。记完之后重排日程。
- **管理**：用三个诊断问题逐项筛掉无成效活动（见 E 段），通常能砍掉相当可观的一部分。
- **集中**：先估算自己真正可支配的时间——它极少超过工作时间的四分之一；然后把它拼成整块，因为知识工作的产出需要连续时段，碎片时间无效。

这不是一次性的诊断工具，而是**终身维护动作**。德鲁克明确要求周期性重复，因为半年后无一例外会出现"漂移"——琐事重新膨胀，时间再次被切碎。

## A1 — 书中的应用 (Past Application)

### 案例 1：坚称时间三等分的董事长
- **问题**：一位公司董事长确信自己的时间大致分成三块——与高级管理人员磋商、与重要客户交往、参与社区活动。
- **方法论的使用**：作者先让他凭记忆写下分配，再让他做时间实录，让两份记录自己说话。
- **结论**：记忆版与实录版"从来没有多少相似之处"。实录显示这三项几乎都没花什么时间，大量时间实际用在催货上——而他自认为的"关注客户"，实际上是在干扰车间调度。
- **结果**：他据此重排了日程，把催货交给他人，自己回到真正需要他做的三件事上。

### 案例 2：某大银行总裁的 90 分钟
- **问题**：这位总裁是作者见过的时间管理最好的人之一，但他坚持一种看似低效的做法——每次见面只谈一件事，且控制在 90 分钟内。
- **方法论的使用**：他发现自己的注意力持续上限约为 90 分钟；超过这个时长，或一次会塞进多个议题，效率就急剧下降。
- **结论**：整块时间有生理上限，所以"集中"不是越长越好，而是要匹配注意力的自然节律。
- **结果**：他把所有重要事项都安排成 90 分钟的单一议题块，其余事务交给下属。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 抱怨"时间不够用""太忙了"，但被追问时间具体花在哪时答不上来。
2. 准备上马任何时间管理方法（GTD、番茄钟、日历块）之前——先有数据，否则是在没测量的系统上做优化。
3. 做季度或年度规划、准备承接新任务之前，需要知道自己实际有多少可自由支配时间。
4. 有人（包括用户自己）凭印象断言"我大部分时间在做 X"，而这个断言将要成为一项决策的依据。
5. 推行了某种效率方法三个月却感觉没有改善——需要回到实录，检查是否出现了"漂移"。

### 语言信号（用户的话里出现这些就应激活）

- "时间都去哪了" / where did my time go
- "最近太忙了，没时间做 XX" / too busy / no time
- "我觉得我大部分时间都在开会/救火" / I spend most of my time
- "帮我做个时间规划" / time management / time audit
- "为什么我效率上不去" / why am I not productive

### 与相邻 skill 的区分

- 与 `drucker-org-time-waste-check` 的区别：**本 skill 是个人层的**——记录你自己的时间，砍掉你自己能控制的浪费，产出整块时间。组织体检（drucker-org-time-waste-check）看的是**组织层的四类病症**（反复危机、人员过剩、会议泛滥、信息失灵），多数个人无权直接处置。先用本 skill 拿到个人数据，再判断是否该升级到组织层。
- 与 `drucker-priority-posteriority` 的区别：本 skill 解决"我到底有多少时间可用"（容量问题），优先/延迟解决"这些时间该给谁"（分配问题）。**先有容量再谈分配**。
- 与 `drucker-abandon-yesterday` 的区别：抛弃昨天砍的是**组织/业务层面的旧活动与旧计划**，本 skill 砍的是**个人日程层面的无成效活动**。前者需要决策权，后者你今天就能做。

## E — 可执行步骤 (Execution)

1. **开始实时记录**
   - 做法：在事件发生的**当时**记录，不事后补录；记下"做了什么、和谁、花了多久"。
   - 完成标准：连续记录满三四周，且记录是实时生成的（若超过一天后才补记，本步不合格，重来）。
   - 判停条件：若用户坚持用周报或记忆回填代替实时记录 → **停止本 skill**，明确告知：靠记忆在生理上就是不可靠的，这一步不能妥协。

2. **重排日程：用三个诊断问题逐项过筛**
   - 对记录表上的每一项活动依次问：
     1. "这件事如果完全不去做，会产生什么后果？"——答案是"什么后果也没有" → 停止做这件事。
     2. "我时间记录上的哪些活动，是别人同样可以做好、甚至做得更好的？" → 分出去。
     3. "我做的哪些事，对你的有效性没有贡献，所以是浪费你时间的？" → 这一问只能靠直接、诚恳地询问他人获得。
   - 完成标准：记录表上每一项都有明确处置（停 / 分 / 保留），且第 3 问至少问过三位同事。
   - 判停条件：若砍完后出现明显的自我纠正信号（某件重要事被误砍），迅速恢复——德鲁克说砍过头极少发生且容易察觉，所以**宁可砍狠**。

3. **估算并集中可自由支配时间**
   - 做法：先算清楚真正能由自己支配的时间有多少（经验值：极少超过工作时间的 1/4），再把它拼成整块。
   - 完成标准：日程中存在明确的、被保护的整块时段；单块时长参考 90 分钟（注意力自然节律）。
   - 判停条件：若可自由支配时间趋近于零（见 B 段），**不要继续**，转而告知用户这套方法在此岗位上失效，应同时启动 `drucker-org-time-waste-check` 做组织层诊断。

4. **建立防漂移机制**
   - 做法：每月定期回顾记录并重排日程；每年至少完整重做两次。
   - 完成标准：用户能说出"下次完整重做实录"的具体时间点。
   - 说明：这一步是本 skill 区别于普通时间管理工具的关键——有效性是习惯养成，不是一次性的技巧掌握。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **可自由支配时间趋近于零的岗位**：被算法实时调度的岗位（平台骑手、在线客服、内容审核）、需要随时响应的值班运维、临床护理一线、以及任何 KPI 被细颗粒度实时监控的岗位。这些角色"集中成整块"在物理上不成立——德鲁克整套时间方法的产出就是"可自由支配时间"，没有它就没有下游。
- **纯执行型任务排期**：如果用户要的只是"把这些事排进日历"，这是日程管理，不需要先做三四周记录。
- **危机期**：组织处于生存危机时（融资断裂边缘、战时），先把火扑灭，实录没有意义。
- **用户已经做过实录且数据仍然有效**（三个月内）：直接进入第 2、3 步，不要重复记录。

### 作者在书中警告的失败模式

- **靠记忆估计时间**（ce07）—— 这是本 skill 要根治的病本身。典型信号：有人说"我大概三分之一时间在 X"，但半年没做过记录。
- **同时做几件事导致整块时间消失**（ce08）—— 判据：同期并行 ≥3 条主线，或任一主线连续无打扰时间 <90 分钟。
- **把"记录"当一次性动作**（漂移）—— 判据：6 个月未重做记录，日程已重新滑回琐事。

### 作者的盲点 / 时代局限

- **样本偏差**：全书案例几乎清一色为 1960 年代男性、最高层、美欧大型机构。书中"每周在家办公一天""每天早上在家工作 90 分钟不接电话"这类建议，隐含假设了一个可以把工作置于家庭之上、不被随时打断的主体——对承担主要照护责任的人几乎不可行。
- **知识工作已被重新定义**：德鲁克假定"知识工作者无法被严格或细致地监督，只能自我指引"。但今天的数字泰勒主义恰恰实现了对知识工作过程的细颗粒度监控。如果你的岗位本身就在被实时度量，这套"自我记录"方案的前提已经松动。
- **咨询顾问立场**：他把"时间属于别人"列为管理者改变不了的四大现实之一，却把解法全部开给个人。若时间被结构性占用（会议 >1/4、人手过剩导致的摩擦 >1/10），个人层面的记录与砍削收效有限——**此时应转到 `drucker-org-time-waste-check`，并意识到那已超出个人权限**。

### 容易混淆的邻近方法论

- **番茄工作法 / 时间盒**：它们优化的是"如何在给定时间内保持专注"，本 skill 先回答的是"你到底有没有给定时间"。顺序不能颠倒。
- **时间日志 App 的自动追踪**：自动工具能解决"实时记录"的负担，但仍需人工回答三个诊断问题——工具不能替代判断。
