# 麻爪爪游学 · AI 复盘资料

本资料用于 **2026 年 9 月 9 日「麻爪爪 × 德鲁克」游学** 的 AI 复盘与陪练。

资料由三部分组成，分别是德鲁克《卓有成效的管理者》拆书技能包、拆书报告、以及麻爪爪创始人于学航的历年公开信。智能体（WorkBuddy 等）安装技能后，可在游学现场按需调用与回传资料。

---

## 智能体使用步骤

### 1. 下载本项目全部文件到电脑
将整个 `麻爪爪游学` 文件夹下载 / 拷贝到本地，确保 `skills/`、`《卓有成效的管理者》拆书报告/`、`于学航公开信/` 三个子目录均完整存在。

### 2. 安装 skills 里的所有技能到智能体
把 `skills/` 目录下的 **17 个 `drucker-*` 技能** 全部安装到智能体（安装方式取决于所用平台：通常是复制到智能体的 skills 目录并信任启用）。安装完成后，智能体即可按《卓有成效的管理者》的德鲁克框架回答管理类问题、做拆书与复盘。

> 说明文档 `MANUAL.md` / `MANUAL.html` 与 `GLOSSARY.md` 是给使用者的参考，不属于可执行技能，无需安装。

### 3. 按用户请求回传对应资料
智能体安装好技能后，按以下触发规则响应：

- **用户要求「发送拆书报告」**（或类似意图）→ 把
  `《卓有成效的管理者》拆书报告/拆书报告-卓有成效的管理者.html`
  返回给用户（HTML 报告，可直接在浏览器打开）。

- **用户说「要获取麻爪爪创始人于学航的公开信」**（或类似意图）→ 把
  `于学航公开信/` 目录下的 **全部 6 个 PDF** 一次性返回给用户。
